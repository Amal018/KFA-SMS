BLOG — HOW TO PUBLISH A POST
============================

Every .txt (or .md) file in this folder is a blog post on blog.php.
Upload a new file = new post. Delete it = post removed.
The sitemap (sitemap.xml) updates itself so Google finds new posts.

FILE NAME → web address
  "tanjore-painting-basics.txt"  →  blog.php?post=tanjore-painting-basics
  Use lowercase words joined by hyphens.

DRAFTS
  Start the file name with "_" (e.g. "_summer-camp.txt") to hide it.

FILE FORMAT
  Title: Summer Art Camp 2027 in Coimbatore
  Date: 2027-03-15
  Description: One or two sentences shown on Google (about 150 characters).
  Image: assets/images/courses/cat-kids.jpg        (optional)
  ---
  Write the article here. A blank line starts a new paragraph.

  ## A heading
  ### A smaller heading
  - a bullet point
  1. a numbered point
  **bold text**   *italic text*
  [link text](course-details.php)   or   [Google](https://www.google.com)
  > a quote

SEO TIPS FOR EACH POST
  • Answer one real question parents ask (e.g. "Which art class is best
    for a 6-year-old?"). Put the main phrase in the Title.
  • Mention Coimbatore and nearby areas naturally — never repeat
    keywords unnaturally; Google penalises that.
  • Link to one or two pages on the site (courses, gallery, contact).
  • Add a real photo from the studio when you can.
  • Aim for one new post a month — consistency matters more than length.
  • Use today's real date.
