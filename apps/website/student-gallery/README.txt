STUDENT GALLERY — HOW IT WORKS
==============================

This folder IS the student gallery. The website reads it every time the
Gallery page (and the home page artwork strip) is opened. Nothing else
needs to be edited.

ADD A CATEGORY
  Create a new folder here. Its name becomes the category button,
  e.g. "Pencil Drawing". Empty folders are not shown.

ADD ARTWORK
  Upload images (JPG, PNG, WEBP, GIF or SVG) into a category folder
  using the DirectAdmin File Manager or FTP. They appear on the site
  immediately — newest uploads first.

NAME FILES LIKE THIS
  "Student Name - Artwork Title.jpg"   → shows title + student name
  "Artwork Title.jpg"                  → shows just the title
  Underscores are turned into spaces ("Night_Sky.jpg" → "Night Sky").

ORDER THE CATEGORIES
  Folders are listed alphabetically. To choose the order, start folder
  names with a number: "01 Kids Colouring", "02 Pencil Drawing" …
  The number is hidden on the website.

HIDE SOMETHING WITHOUT DELETING IT
  Start the folder or file name with an underscore, e.g. "_Old Work".

TIPS
  • Resize photos to about 1600 px on the longest side before uploading
    so pages load quickly on phones.
  • Only upload artwork you have permission to publish (parent consent
    for children's work and names).
  • The demo images currently in these folders are placeholders —
    delete them and upload real artwork before launch.
