OUR TALENTED STUDENTS — HOW IT WORKS
====================================

Every folder in here is one student. The Gallery page ("Our Talented
Students") and each student's own page are built from these folders
every time they are opened. Nothing else needs to be edited.

  talented-students/
      01 Aaradhya S/
          profile.jpg                       ← the student's photo (card + page)
          01 My Dream Home - Colouring.jpg  ← artwork: "My Dream Home", medium "Colouring"
          02 Butterfly - Drawing.jpg
          info.txt                          ← optional details (see below)
      02 Vihaan K/
          ...

ADD A STUDENT
  Create a folder named after the student (e.g. "Meera R"), put a
  photo called profile.jpg inside, then upload their artwork.
  The new student card and page appear immediately.

REMOVE A STUDENT
  Delete their folder (or rename it to start with "_" to hide it
  without deleting). The card and page disappear immediately.

ARTWORK FILE NAMES
  "Title - Medium.jpg"  → shows the title and the medium
  "Title.jpg"           → shows just the title
  A number at the start ("01 ", "02 ") sets the order and is hidden.
  JPG, PNG, WEBP, GIF and SVG are supported.

info.txt (optional — any line can be left out)
  Course: Kids Art Class
  Age: 6
  About: A creative and cheerful learner who loves colours.
  Quote: Small Hands,|Big Imagination      (| = new line)
  Pronoun: her                              (her / his / their)

ORDER OF STUDENTS
  Folders are listed alphabetically; start names with numbers
  ("01 Aaradhya S", "02 Vihaan K") to choose the order.
  The number is not shown on the website.

The student's page address comes from the folder name, e.g.
"01 Aaradhya S" → gallery page link student-gallery.php?student=aaradhya-s

PRIVACY: only publish children's names, photos and ages with parent
consent. The current folders are DEMO content — replace before launch.
